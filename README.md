# Keiko React Landing Page

A simple React landing page in the Keiko branding style.

## Prerequisites

- Node.js
- npm

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the local development server:

   ```bash
   npm run dev
   ```

3. Open the `localhost` URL printed by the tool in your browser.

## Build

```bash
npm run build
```
